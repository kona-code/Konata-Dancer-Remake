# NO_AI Policy

**Status: Strictly Enforced**
**Scope: Entire Repository**

This repository is strictly **NO_AI**.

By contributing to, accessing, modifying, building, testing, distributing, or otherwise interacting with this repository, you agree to comply with this policy.

## 1. Absolute Prohibition

The use of **any artificial intelligence, machine learning, automated learning system, generative model, neural network, language model, embedding model, or substantially similar technology** in connection with this repository is prohibited.

This prohibition applies regardless of:

* Provider, vendor, organization, or individual operating the technology.
* Whether the technology is commercial, open-source, self-hosted, local, remote, cloud-based, or embedded.
* Whether the technology is free, paid, private, public, experimental, or internal.
* Whether the technology is used directly or indirectly.
* Whether the technology is used during development, testing, review, documentation, deployment, maintenance, analysis, or distribution.

## 2. No Machine Learning

No machine-learning system may be used to:

* Generate or modify source code.
* Generate or modify documentation.
* Generate commits, patches, pull requests, issues, comments, or reviews.
* Analyze, classify, summarize, transform, or evaluate repository contents.
* Produce tests, test data, benchmarks, examples, or fixtures.
* Make development or architectural decisions.
* Automatically inspect or process repository contents for learning purposes.
* Train, fine-tune, evaluate, benchmark, or otherwise operate a machine-learning model using repository data.

## 3. No Indexing or Data Ingestion

Repository contents may **not** be submitted to, ingested by, crawled for, indexed by, embedded into, or otherwise processed by AI/ML systems.

This includes, without limitation:

* Source code.
* Documentation.
* Issues and discussions.
* Commit history.
* Pull requests.
* Configuration files.
* Test data.
* Build artifacts.
* Logs.
* Examples and fixtures.
* Metadata associated with the repository.

No vector database, embedding service, semantic index, AI search system, retrieval-augmented generation system, or comparable technology may be used to index or retrieve repository content.

## 4. No Generative AI

Generative AI must not be used to create, rewrite, translate, summarize, review, explain, optimize, refactor, debug, or otherwise contribute content to this repository.

This includes, but is not limited to:

* Chatbots.
* Coding assistants.
* Code-generation systems.
* AI-powered IDE features.
* AI-powered search or documentation tools.
* Autonomous coding agents.
* AI review tools.
* AI-powered commit or pull-request generators.

## 5. No Indirect Use

The prohibition applies even when the AI system is not explicitly operated by the contributor.

Contributors must not knowingly use development tools, services, extensions, integrations, CI systems, hosting services, or other infrastructure that automatically submits repository content to prohibited AI/ML systems.

A tool does not become permissible merely because its AI/ML functionality is optional, hidden, automatic, or provided by a third party.

## 6. Human Authorship and Processing

Repository contributions must be produced and reviewed by humans without prohibited AI/ML assistance.

Human-operated deterministic tools are permitted where they do not contain or invoke prohibited AI/ML functionality and do not submit repository contents to prohibited systems.

## 7. No Exceptions by Default

There are **no implied exceptions** to this policy.

Claims that a particular system is:

* "only autocomplete,"
* "only an index,"
* "only a search engine,"
* "only a suggestion system,"
* "not really AI,"
* "just using an API,"
* "only locally hosted,"
* "open source,"
* "not training on the data,"
* or "only analyzing metadata"

do not override this policy when the system falls within the prohibited categories described above.

Any exception must be explicitly authorized by the repository owner **in writing before use**. Silence, absence of enforcement, or prior accidental use does not constitute authorization.

## 8. Contributor Responsibility

Every contributor is responsible for ensuring that their contributions comply with this policy.

If a contributor discovers that prohibited AI/ML was used in connection with repository content, they must disclose the incident to the repository owner and must not continue the prohibited use.

Contributors must not intentionally conceal prohibited AI/ML use.

## 9. Enforcement

Any contribution that violates this policy may be rejected, removed, reverted, or otherwise excluded from the repository.

Access to the repository or participation in the project may be revoked for intentional or repeated violations.

The repository owner reserves the right to request clarification regarding the provenance and creation process of a contribution when reasonably necessary to enforce this policy.

## 10. Interpretation

This policy is intentionally strict.

Where there is reasonable uncertainty about whether a technology, service, feature, or workflow constitutes AI/ML use, **do not use it with this repository until the repository owner has explicitly determined that it is permitted**.

The absence of a technology or service from an example in this policy does not make that technology or service permissible.

## 11. Governing Rule

**If it uses artificial intelligence, machine learning, model inference, embeddings, AI indexing, or substantially similar automated intelligence to process, generate, learn from, or analyze repository content, it is prohibited unless explicitly authorized in writing.**

**NO_AI means NO_AI.**
